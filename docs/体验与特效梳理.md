# 体验与特效梳理（2026-10-01）

只谈**体验、手感、炫酷度**。机制和数值一律不动。

---

## 家底（先确认什么已经有了）

避免提出早就存在的东西：

- **CSS 动画 22 个**：光晕呼吸 `auraPulse`、热度脉动 `heatBeat`、热度变色 `heatHue`、
  FEVER 流动 `feverFlow`、危险带 `dangerPulse`、震屏两档 `shake`/`shakeBig`、
  瞬落砸落 `slamFall`、狂风流 `windFlow`、称号弹出 `rankPop`、飘字 `popUp`、
  灰线预警 `gwarnPulse`、事件脉冲 `evPulse`、盘面闪 `boardFlash`/`boardFlashBig` 等
- **canvas 特效 7 套**：粒子（硬上限 110）、消行扫光 `sweeps`、落点涟漪 `rings`、
  硬降残影 `trails`、激光柱 `beams`、余烬 `embers`、落地压扁 `squash`
- **音效** 9 种 × 3 套音色包，**震动** 22 处，**BGM** 3 首（随热度变速、
  FEVER 变调、暗幕走低通压闷）

底子不薄，缺的不是"数量"，是**分配**。

## 贯穿性问题：好事的表现比坏事弱

| | 表现强度 |
|---|---|
| 暗幕 | 全盘滤镜压暗 + 音乐低通 |
| 镜像 | 盘面紫色虚线描边（持续 8 秒） |
| 狂风 / 瞬落 | 全屏 `.evfx` 覆盖层动画 |
| 封锁 | 整列画成墙 |
| **压实** | **只有一下震屏** |
| **填实** | **只有一下震屏** |
| **缓流** | **只有一圈边框换色** |

事件权重已经改到接近对半（有利 48.4%），但**表现强度还是一边倒**。
玩家潜意识学到的是「事件 = 要倒霉」，有利事件等于白加。

## 按「浪费掉的情绪」排序

### P0-1　全消只有震屏 + toast

**现状**：`shake(true)` + `showToast(label)`，和打四行几乎没区别。

**问题**：全消是俄罗斯方块里最稀有的成就，一整局可能一次都打不出来。
而 toast 是共享通道，紧接着触发 FEVER 就会被顶掉 —— 可能连那行字都看不到。

**建议**：给它一套独占表现。整屏白闪一次 + 盘面从底向上一道横扫光 +
专属音（现在和四行共用 `tetris`）+ 长震动。飘字走 `popScore` 而不是 toast，
因为飘字不会被别的消息冲掉。

### P0-2　破纪录只有一句 toast

**现状**：`showToast('破纪录！')`，没了。

**问题**：刷分游戏里情绪最高的一下，用了最弱的通道。而且它在对局中途触发，
那时 toast 正被消行、FEVER、里程碑反复占用。

**建议**：数字本身做文章 —— SCORE 那一格金色高亮并放大回弹，
盘面边框闪一次金，配独立音。结算页也该把「新纪录」单独标出来，
而不是混在统计行里。

### P0-3　冰冻/解冻的反馈走错了通道 ✅ 已做

**更正**：最初写成「解冻零反馈」是错的 —— 当时 grep 时 `-A6` 截断了，
没看到函数尾部。它其实有 `burstRow` 碎屑 + toast + 音效 + 震动。

**真正的问题**：走的是 **toast 这个共享通道**。解冻往往和消行同时发生，
那一下正好会被消行的 toast 顶掉，等于没解释。而冰冻发生时只有通用的
事件音，玩家不知道是哪一行被冻了。

**问题**：这是全游戏最容易让人懵的瞬间 —— 行明明凑满了却不消，只是颜色变了。
不给反馈，玩家会以为是 bug。冰冻本身也只有通用的事件音，没有专属表现。

**建议**：解冻时那一行做碎冰效果（现成的 `boom` 碎屑换成冰色）+ 玻璃碎裂音 +
一行飘字「解冻　再消一次」。冰冻发生时给那行一道霜白扫过。
**这条不是炫酷，是把规则讲清楚**，优先级最高的一类。

### P1-1　热度爬到顶之后视觉封顶

**现状**：`HEAT_TIERS = [4, 8, 14]` 四档。第 3 档横跨 ×8.5~×13.6
（热度 90~309），×14 以上全挤进第 4 档，而倍率实际能到 ×35+。

**问题**：实测截图里 ×8.5 和 ×35 的盘面**几乎一模一样**。
辛苦从 ×14 爬到 ×35，屏幕上没有任何变化 —— 爬升的回报被截断。

**建议**：第 4 档之上再加一到两档（光晕换色 + 色相流转加速 + 边框更宽），
或者让第 4 档内部随倍率连续插值（现在已经有 `q = Math.round(m*2)` 的
半档机制，往上延伸即可，不必新增离散档）。

### P1-2　连击没有递进

**现状**：只有 `combo >= 5` 一个开关（`body.hotcombo`）。

**问题**：连 5 次和连 15 次长得完全一样，连击这条线在 5 之后就没有追求了。

**建议**：按 5 / 10 / 15 分段加码，或让 `hotcombo` 的光晕强度跟着 combo 数连续变化。
顺带 combo 徽章本身可以做数字跳动。

### P1-3　三个新机制没有专属表现

**现状**：灌注 / 填实只有通用 `boom` 碎屑 + `shake`；缓流只有一圈边框色。

**问题**：玩家认不出刚才发生了什么。灌注和重锤的碎屑是同一套，
但两者效果相反（一个把堆压矮、一个把洞填平）。

**建议**：
- **灌注**：被填的格子从落点**自上而下逐格亮起**（像灌水），配上升音
- **填实**：被填的洞同时闪一下，配「咔」的实心音
- **缓流**：灰线预警条**停住并变色**（现在的边框色太含蓄），
  配一个明确的「停」音；结束前 2 秒预警条重新开始走

### P2　开局与结算两头偏朴素

- **开局**：除狂欢局报幕外没有仪式感。可以给第一块方块一个下落入场动画。
- **结算**：统计齐全（峰值倍率 / 最大一击 / 危险区 / 变异块 / 宝箱 /
  四行 / T-SPIN / 全消 / 梭哈 / 换牌）但呈现是平铺的列表，
  数字可以逐行滚动入场，称号可以做得更重。

---

## 不建议动的

- **再加粒子 / 震屏**：已经有了，而且粒子有 110 硬上限，加了会挤掉消行粒子
- **更多音效种类**：9 种 × 3 套已经够用，问题在于**哪些时刻没分到音**，不在总数
- **全屏特效堆叠**：`.evfx` 那套已经验证过 60fps，但同时叠多个会吃掉余量

## ✅ 实现结果（2026-10-01）

| | 做了什么 |
|---|---|
| P0-1 全消 | 整屏白闪 + 全盘双色扫光 + 爆环 + 飘字（走 pop 不走 toast）+ 叠音 + 长震。和四行彻底拉开 |
| P0-2 破纪录 | 分数格金色高亮回弹（玩家盯着的地方）+ 飘字 + 独立音，toast 保留 |
| P0-3 冰冻/解冻 | 冰冻给那行一道霜白扫光 + 音；解冻从 toast 改走 pop 通道 |
| P1-3 灌注 | 自上而下绿色扫光（像灌水）+ 上行音 |
| P1-3 填实 | 蓝色碎屑 + 整行同闪（和灌注区分：绿/扫 vs 蓝/闪） |
| P1-3 缓流 | 灰线预警条停住并变青 + 「停」音 + 底行扫光 |
| P1-3 压实 | 补音效和震动（原来只有一下震屏） |
| P1-1 热度 | 加第 5 档（×22 起），顶档徽章色相流转 + 光晕 .5s 脉动。结算评语也加一档「失控」 |
| P1-2 连击 | 5 / 10 / 15 三段递进，光晕一段比一段急、徽章一段比一段亮 |

**性能验收**（4× 降频 40 秒，10 种事件轮番触发 + 顶档热度 + 15 连击 +
全消和破纪录特效每 3 秒轰一次）：
FPS 60.0、p99 18.6ms、卡顿 0、长任务 0、内存 9.5MB、
粒子峰值 8/110、扫光池 ≤2。余量充足。

**P2（开局/结算两头）暂未做** —— 改动面大且收益最低，留到后面。

## 实现顺序建议

1. **P0-3 解冻**（讲清规则，不是炫酷，最该先做）
2. **P0-1 全消** + **P0-2 破纪录**（两个最大的浪费掉的情绪）
3. **P1-3 三个新机制的专属表现**（刚加的东西，趁热补上）
4. **P1-1 热度顶档延伸**（改动面稍大，要重测性能）
5. **P1-2 连击递进**、**P2 两头**

每一步做完都要跑 4× 降频性能（现在的基线是满帧 60.0 / 长任务 0），
因为这些都是加法。
