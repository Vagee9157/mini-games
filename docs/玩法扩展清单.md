# 玩法扩展清单（2026-10-03）

只列玩法，不含特效（那份在 `体验与特效梳理.md`）。

---

## 先确认现有的

**方块侧**：金块(纯加分) / 重锤(塌实) / 炸弹(炸一圈) / 激光(打穿一列) /
灌注(填实下方) / Hold / 换牌(花热度)

**盘面事件**：压实 / 缓流 / 暗幕 / 镜像 / 地震 / 冰冻 / 狂风 / 封锁 / 瞬落

**节奏与倍率**：热度 / 燃点(涨得快就点着) / 深局加成 / FEVER / 热流 /
险区加成 / 压哨 / 连击 / B2B

**决策点**：梭哈 / 换牌 / 要不要赖在危险区

**元层**：狂欢局(30%+保底) / 宝箱 / 里程碑 / 段位·最强·生涯

## 四个缺口

1. **目标感** —— 除了「活下去 + 刷分」没有任何别的目标
2. **资源管理** —— 热度是唯一资源，而且只能花在换牌一处
3. **风险自选** —— 险区是唯一「主动冒险换收益」的，而且很被动
4. **局间成长** —— 每局完全独立，上一局的任何东西都不留到下一局

---

## A. 目标感（缺口最大）

**A1. 每局契约** ⭐推荐
开局发 2~3 个随机目标：「打 3 次 T-spin」「不用 Hold 活过 50 行」
「一次消 4 行 ×2」「30 秒内消 10 行」。完成给热度或倍率。
→ 把「我在干什么」从模糊的刷分变成具体的几件事。成本中等。

**A2. 彩虹行**
随机标记盘面上的一行，消掉它给大额奖励，30 秒不消就换一行。
→ 给盘面一个看得见的目标，成本低。

**A3. 悬赏块**
NEXT 里某一块被标记，把它消掉（或放进指定列）给奖励。
→ 比彩虹行更需要规划，因为你知道它几步之后到。

**A4. 目标链**
完成一个解锁下一个，奖励递增，死了整条链作废。
→ 自带「要不要再贪一个」的张力，和梭哈同源但跨度更长。

**A5. 禁区**
随机标记 2~3 列为禁区，30 秒内别往里放块，撑住给奖励。
→ 唯一一个「不做某事」类目标，和其它都不重复。

## B. 资源管理（让热度变成真货币）

**B1. 热度商店** ⭐推荐
对局中随时可以花热度买：清掉最底一行 / 换掉整个 7-bag /
冻结灰线 15 秒 / 预知 5 个 NEXT / 买一次保命。
→ 热度从「只能看的倍率」变成「花还是不花」的持续决策。
现在换牌已经是这个雏形，把它扩成一个面板即可。成本中等。

**B2. 保命符**
花一大笔热度买「堆到顶不死」一次，触发时压实整个盘面。
→ 深局的终极保险，贵到你会犹豫。

**B3. 热度兑分**
主动把当前热度全部兑成分数，兑完归零。
→ 「见好就收还是继续滚」，深局最后一手的抉择。

**B4. 预知**
花热度在 30 秒内多看 3 个 NEXT。
→ 最朴素的能力购买，成本极低。

**B5. 存热**
把热度存进一个罐子（不衰减），之后一次性倒出来。
→ 对抗衰减机制本身，但存的时候不吃倍率，有代价。

## C. 风险自选

**C1. 开局加码**
开局可选「灰线翻倍」换「分数翻倍」，整局有效、不可反悔。
→ 一句话的机制，给熟练玩家一个自我证明的开关。成本低。

**C2. 血契**
接受一个负面词条（本局不能用 Hold / 看不见 NEXT / 灰线快 50%）
换整局倍率加成。可以叠，越叠越疯。
→ 把难度选择变成有收益的主动行为，而不是菜单里的档位。

**C3. 阶梯赌** ⭐推荐
梭哈的升级版：赢了之后可以选择**继续加注**，连赢倍率叠乘，
输一次全部清零。
→ 直接复用现有的梭哈框架，成本最低的高回报改动。

**C4. 深水区**
主动把危险线往下调一格，换更高的险区加成，可多次下调。
→ 把「赖在高处」这个隐性玩法显性化、可量化。

**C5. 限时悬赏**
随机出现「20 秒内拿到 X 分」的悬赏，接了之后失败要扣热度。
→ 梭哈是比行数，这个是比分数，手感不同。

## D. 局间成长（现在完全没有）

**D1. 开局三选一** ⭐推荐
每局开始从一池被动里挑一个：初始热度 +50 / 金块概率翻倍 /
梭哈档位 +1 / 事件间隔 +50% / 深局加成提前 20 行。
→ roguelite 的核心循环，单价最高的一条：每局开头就不一样了，
重开的理由从「上一局手滑」变成「这次想试另一套」。成本中等。

**D2. 天赋树**
用生涯累计分解锁永久被动。
→ 给生涯累计分一个用途（现在它只用来算段位）。
但要小心：永久变强会让早期局变得没意义。

**D3. 每日任务**
三个任务，完成给第二天开局加成。
→ 有现成的「今日局数」基建（北京时间日切）可以复用。

**D4. 连胜**
连续几局达到某个线，倍率累积，断一次清零。
→ 跨局的张力，成本低。

## E. 新方块（盘面互动）

**E1. 磁铁块**　锁定后把周围同色块吸附过来
**E2. 幽灵块**　可以穿过已有方块，落到最底下
**E3. 复制块**　下一块和这块完全一样（含变异）
**E4. 分裂块**　落地后裂成两半各自继续下落
**E5. 染色块**　把落点那一行全染成同色；同色整行消除有加成
**E6. 齿轮块**　落地后把周围 3×3 顺时针转 90°
**E7. 炸裂块**　消行时不消失，而是弹到盘面顶部变成灰块（负面变异，加风险）

## F. 新事件

**F1. 重力翻转**　盘面上下颠倒一次（一次性，极混乱）
**F2. 列交换**　随机交换两列
**F3. 潮汐**　灰线反过来从上往下压
**F4. 静默**　20 秒内不出任何事件，但倍率翻倍（风平浪静的高收益）
**F5. 洗牌**　把 NEXT 队列整个重排
**F6. 返祖**　盘面所有特殊格（冰冻/灰线）变回普通块

## G. 节奏变化

**G1. 冲刺段**　每 50 行进入 20 秒：灰线停、下落极快、消行分数翻倍
**G2. 节拍器**　跟着 BGM 节拍落块给额外热度（音乐基建已有，会变速）
**G3. 加速带**　某几行标记为加速带，方块经过时瞬间落底

## H. 对比与回放（单机也成立）

**H1. 幽灵回放** ⭐推荐
实时对比「自己最高分那局在同样行数时的分数」，侧栏显示领先/落后多少。
→ 刷分游戏里最便宜也最有效的一条：把「刷分」变成「追自己」。
只要在破纪录那局记下每 10 行的分数快照即可，成本极低。

**H2. 每日种子**
每天固定一个方块序列，自己和自己比。
→ `setSeed` 和北京时间日切都是现成的。

**H3. 死亡回放**
结算页回放最后 10 秒。
→ 成本高（要录状态），收益一般，排最后。

## 优先级

**第一梯队**（改变游戏性质，值得先做）

| | 为什么 |
|---|---|
| **D1 开局三选一** | 唯一能让「每局都不一样」的机制，重开理由从手滑变成想试新搭配 |
| **A1 每局契约** | 填最大的缺口（目标感），玩家终于有「我在干什么」的答案 |
| **H1 幽灵回放** | 成本最低的高回报：把刷分变成追自己，只要存一组快照 |
| **C3 阶梯赌** | 直接复用梭哈框架，把一次性的赌变成可以滚的赌 |

**第二梯队**（把现有系统做深）

B1 热度商店 / C1 开局加码 / A2 彩虹行 / F4 静默 / G1 冲刺段

**第三梯队**（新鲜感，但不改变结构）

E 系列新方块 / F 系列新事件 / D3 每日任务 / H2 每日种子

**要谨慎的**

- **D2 天赋树**：永久变强会让早期局失去意义，而且和「每局独立」的现有结构冲突最大
- **E7 炸裂块**：唯一的负面变异块，但现在坏事件已经占 61.5% 权重，再加要同步减
- **F1 重力翻转**：极混乱，可能直接判死，要像 EV_DEADLY 那样在危险区排除
- **H3 死亡回放**：要录状态，成本和收益不成比例

## 每条都要过的两关

1. **会不会把分数推飞** —— 任何给倍率/热度的机制都要先算它的平均贡献，
   再决定要不要动梯子。燃点就是没算这一步才失控的。
2. **标准版隔离** —— 所有新机制都必须在 `CRAZY` 门禁之后，
   标准版的卖点是「纯 Guideline，什么都不加」。
