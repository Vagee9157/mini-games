浏览器里打开就能玩的小游戏，纯前端，没有后端和账号。

**在线地址** → https://vagee9157.github.io/mini-games/

## 怎么玩

**电脑**

| 键 | 作用 |
|---|---|
| `←` `→` | 左右移动（按住连发） |
| `↓` | 软降 |
| `空格` | 硬降，直接落底 |
| `↑` / `X` | 顺时针旋转 |
| `Z` / `Ctrl` | 逆时针旋转 |
| `C` / `Shift` | 暂存当前块 |
| `P` / `Esc` | 暂停 |
| `R` | 重开 |
| `M` | 静音 |

**手机**

纯按键操作。左手一组管移动（`←` `→` `软降`），右手一组管动作（`↺` `↻` `落底`），点 HOLD 框暂存。

竖屏按键在棋盘下方，横屏会自动分到左右两侧贴着拇指，NEXT 也会变成竖排多显示几个。

点右上角**「游戏模式」**可以收起页面上的壳，把棋盘放到最大，同时防止屏幕自动熄灭。iPhone 的 Safari 不允许网页真全屏，想要彻底没有地址栏，用 Safari 的分享菜单「添加到主屏幕」，之后从图标打开就是全屏，而且直接进游戏模式。

```
tetris/
  index.html
  tetris.css
  tetris.js
```

## 加一款新游戏

1. 新建一个文件夹，比如 `snake/`
2. 里面的 HTML `<link>` 上 `../assets/shared.css`，配色和顶栏就有了
3. 在首页 `index.html` 的 `.grid` 里加一张 `.card live` 卡片，指向新文件夹
4. push，GitHub Pages 会自动更新

## 换方块样式

顶栏「样式」里可以随时换，**2 套配色 × 4 种画法 = 8 个组合**，选完记在这台设备上。

- **配色**：`高区分`（青调亮、蓝压暗、紫偏红，三个蓝色系不会挤在一起，饱和度略降久看不累）/ `原配色`
- **画法**：`宽缝`（靠留白分离）/ `柔和`（描边不接近白，圆角大）/ `暗圈`（每块先压暗边再描亮边，相邻色分得最开）/ `纯色`（完全不描边，最干净）

面板贴在屏幕底部、开着的时候棋局会冻住，方便边挑边看棋盘上的实际效果。

## 关于分数

最高分存在浏览器的 localStorage 里，只在这台设备这个浏览器上。清缓存、换设备、开无痕都会丢。
