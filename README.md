## 怎么玩

**电脑**

| 键 | 作用 |
|---|---|
| `←` `→` | 左右移动（按住连发） |
| `↓` | 软降 |
| `空格` | 硬降，直接落底 |
| `↑` / `X` | 顺时针旋转 |
| `Z` / `Ctrl` | 逆时针旋转 |
| `C` / `Shift` | 暂存当前块 |
| `P` / `Esc` | 暂停 |
| `R` | 重开 |
| `M` | 静音 |

**手机**

纯按键操作，一排四个：`左移` `右移` `落底` `变换`，点右侧 HOLD 框暂存。软降没有按钮，键盘 `↓` 还留着。

竖屏棋盘在左、右侧一条窄栏放 NEXT / HOLD / 计分；横屏按键自动分到左右两侧贴着拇指。NEXT 上排是马上要来的那个，下排并排放之后两个。

点右上角**「游戏模式」**可以收起页面上的壳，把棋盘放到最大，同时防止屏幕自动熄灭。iPhone 的 Safari 不允许网页真全屏，想要彻底没有地址栏，用 Safari 的分享菜单「添加到主屏幕」，之后从图标打开就是全屏，而且直接进游戏模式。

## 离线也能玩

装了 Service Worker（`sw.js`），**联网打开过一次之后，断网照样能玩**——高铁、地铁、飞机上都行。

- 页面本身走「网络优先」：有网时第一时间拿到新版，没网就用存下来的。
- CSS / JS / 图标走「缓存优先」，快且离线可用。文件名里带内容哈希，改了就是另一个 URL，不会读到旧的。
- `sw.js` 由 `bump.py` 生成，**别手改**：资源清单和版本号都是算出来的，任何文件一变整体版本号就变，浏览器会自动重新缓存并清掉旧的。
- 想更彻底就「添加到主屏幕」，从图标打开是全屏，跟装了个 App 一样。

字体走的是 Google Fonts，离线时会降级到系统字体（iOS 上是 PingFang SC / Menlo），排版不受影响。

## 改完样式记得跑一下

```bash
python3 bump.py
```

它会把 CSS / JS 的内容哈希写进 HTML 的引用里（`tetris.css?v=4a423810`）。
不跑的话，GitHub Pages 的缓存会让回访的人拿到**新 HTML 配旧 CSS**，布局直接错乱。

## 加一款新游戏

1. 新建一个文件夹，比如 `snake/`
2. 里面的 HTML `<link>` 上 `../assets/shared.css`，配色和顶栏就有了
3. 在首页 `index.html` 的 `.grid` 里加一张 `.card live` 卡片，指向新文件夹
4. push，GitHub Pages 会自动更新

## 黑八的几个实现要点

- **物理是自己写的**：球撞球按等质量弹性碰撞沿法线换速度，撞库带损耗，摩擦按「每秒衰减到 20%」算（跟帧率无关）。每帧按最快那颗球的速度切子步，一步走不超过半个球——不然快球会直接穿过去。
- **满力一杆约 3 秒停**。最早摩擦定得太小要滚五六秒，等得烦。
- **辅助线画两条**：白球会停在哪（虚线 + 空心圈）、被撞的球会往哪走（黄线）。没有第二条就只能靠猜。
- **规则按真的来**：开球不定组、第一颗进的球定组、进了自己的球继续打、先碰对方球算犯规、白球落袋给对手自由球（可以直接拖白球）、清完自己那组才能打 8 号。**开球把 8 号打进是重摆不是判负**。
- **袋口判定 1.58 倍球径**。再大一点就变成「球沿着库边滚过角落也掉」。
- **球面按真的画**：全色球（1–7）整颗是本色、中间一个白圆写号码；花色球（9–15）是**白球体中间一条彩带**，号码印在彩带上——一开始做反了，画成了彩色球中间夹白条。彩带占球高约一半，上下各留一截白。6 和 9 底下加一横，倒过来不会认错。

## 黑八的 AI 是怎么想的

对「我能打的每颗球 × 六个袋」全算一遍：

1. 目标球要进某个袋，就得从它背后某一点撞它——那点叫**幽灵球位置**（目标球中心沿「球→袋」方向往回退一个球径）。白球瞄那儿就行。
2. 算**切角**：白球来的方向和「球→袋」方向的夹角。越接近正碰越稳，夹角过大（cos < 0.22）直接放弃。
3. 查两段路：白球到幽灵球、目标球到袋，中间有没有别的球挡着（点到线段距离 < 1.92 倍球径算挡）。
4. 挑最直最近的一杆打，力度按「距离 + 切角」算——切得越薄越要用力。
5. 最后给瞄准角加一点随机误差，不然它百发百中就没法玩了。

实测八次不同距离的角袋球，八进八。挡住时会换目标或者选择轻推，不硬轰。

三种模式共用一套物理和规则：**单人清台**（8 号留最后，比谁杆数少，记最好成绩）/ **人机对战** / **双人同屏**。

## 泡泡龙的几个设计取舍

- **发射器是只小恐龙**——这系列（Puzzle Bobble）的主角本来就是 Bubble Bobble 那两只小恐龙。它会跟着瞄准方向侧身，眼珠子也跟着看。
- **瞄准线把撞墙反弹算进去**，末端画落点圈。撞墙打斜角是这类游戏的核心乐趣，没有辅助线在小屏上根本瞄不准。
- **点小恐龙旁边那颗就换手**（键盘 Shift）。手里颜色不合适时没这个很难受，现代泡泡龙基本都有。
- **四色不是五色**。八列的小盘子上五色太难凑三连，打十发不中很挫败。
- **掉落比直接消更值钱**（20 分 vs 10 分），鼓励去打支撑点而不是闷头消三个。
- **还剩两行时底线烧红**、计分条跟着变色，给个反应时间。

## 换方块样式

顶栏「样式」里可以随时换，**2 套配色 × 4 种画法 = 8 个组合**，选完记在这台设备上。

- **配色**：`高区分`（青调亮、蓝压暗、紫偏红，三个蓝色系不会挤在一起，饱和度略降久看不累）/ `原配色`，外加四套**单色**——七种方块同一个颜色，只看形状不看颜色：
  - `青` 和界面一个调子
  - `琥珀` 八十年代单色 CRT 那种暖黄，低蓝光，晚上玩最舒服
  - `月白` 最接近线稿，极简
  - `薄荷` 老绿屏终端的味道

  单色下相邻方块颜色一样，所以会自动补一道暗边界，形状照样分得清。
- **画法**：`宽缝`（靠留白分离）/ `柔和`（描边不接近白，圆角大）/ `暗圈`（每块先压暗边再描亮边，相邻色分得最开）/ `纯色`（完全不描边，最干净）

面板贴在屏幕底部、开着的时候棋局会冻住，方便边挑边看棋盘上的实际效果。

## 难度：不加速，改成底部顶灰线

下落速度**全程不变**。难度靠底部每隔一段时间顶上来一行灰色虚线（每行带一个缺口，能正常消掉），把整盘往上挤。间隔从 30 秒起，每升一级快 2.5 秒，最快 12 秒一行。棋盘底边那道细线是倒计时，快满时变红。

比"越来越快"讲道理——后期不至于变成纯拼手速。

## 音效

全部 WebAudio 现合成，没有音频文件。顶栏喇叭图标开关，偏好存起来。

消行走的是 C 大调上行琶音——**消几行就多爬几个音**，四行（Tetris）整条音阶爬完，配低音扫频和噪声；**连击越多整体音高越亮**（每连一次升半音，封顶 8 次）。T-spin 换小调，听得出不一样。硬降是噪声冲击加下沉低音，落地、旋转、升级各有各的短音。master 后面挂了压限器，多个音叠在一起不会爆。

## 存档

三样东西存在浏览器的 localStorage 里，只在这台设备这个浏览器上：

- **最高分**
- **没打完的那一局** —— 每次方块落地时存一次，切后台、锁屏、关页面也会存。下次打开开始页会多出「接着上次玩」，点它接着打；点「开始」就是新的一局，旧存档丢弃。游戏结束时存档自动清掉。
- **样式和音效偏好**

清缓存、换设备、开无痕都会丢。
